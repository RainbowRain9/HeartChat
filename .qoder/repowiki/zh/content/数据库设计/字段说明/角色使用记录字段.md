## 角色使用记录字段说明

`roleUsage` 集合用于记录用户对各个角色的使用情况，包含以下核心字段：

- **userId**: 用户ID，关联 `user_base` 表，标识使用角色的用户
- **roleId**: 角色ID，关联 `roles` 表，标识被使用的角色
- **usageCount**: 使用次数，数值类型，记录该用户使用该角色的总次数
- **lastUsedTime**: 最后使用时间，日期类型，记录该用户最后一次使用该角色的时间
- **createTime**: 创建时间，统计记录创建的时间戳
- **updateTime**: 更新时间，统计记录最后更新的时间戳

该集合通过 `roleId + userId` 的复合唯一索引确保每个用户-角色组合仅有一条统计记录，支持高效的角色使用分析和个性化推荐。

## 角色使用频率统计方法

角色使用频率通过 `usageCount` 字段进行统计，采用实时递增的计数方式。每当用户开始与某个角色对话时，系统会自动更新该用户的该角色使用次数。

统计方法的核心逻辑如下：
1. 系统首先查询是否存在该用户-角色组合的现有统计记录
2. 如果存在，则将 `usageCount` 字段值增加1
3. 如果不存在，则创建新的统计记录，`usageCount` 初始化为1

这种设计确保了使用次数的准确性和实时性，为角色推荐算法提供了可靠的数据基础。`usageCount` 字段需要实时更新以保证统计数据的准确性。

## 最近使用时间更新逻辑

`lastUsedTime` 字段的更新逻辑与角色使用频率统计同步进行。每次用户使用角色时，系统不仅会递增 `usageCount`，还会将 `lastUsedTime` 更新为当前服务器时间。

具体更新规则：
- 使用 `db.serverDate()` 获取服务器时间，确保时间一致性
- 在更新现有记录或创建新记录时，同时设置 `lastUsedTime` 和 `updateTime` 为当前时间
- 该字段用于排序和筛选最近使用的角色，支持"最近使用"功能的实现

通过这种机制，系统能够准确追踪每个用户对各个角色的最新互动时间，为角色推荐和使用历史展示提供时间维度的数据支持。

## 常用角色推荐实现

在角色选择页面，系统结合 `roleUsage` 集合的统计数据和聊天记录，实现了智能的角色推荐功能。推荐逻辑主要基于两个维度：消息数量和使用频率。

实现流程如下：
1. 页面加载时，调用云函数获取角色列表
2. 同时查询 `roleUsage` 集合，获取用户对各个角色的使用统计
3. 查询 `chats` 集合，统计每个角色相关的消息数量
4. 根据消息数量对角色进行降序排序，选择消息数量最多的前两个角色作为推荐角色
5. 如果消息数量不足，则补充使用 `isRecommended` 标记的角色

这种多维度的推荐策略确保了推荐结果既反映用户的实际使用习惯，又能引导用户发现高质量的角色。

## 使用历史展示实现

角色使用历史的展示主要通过角色卡片的详情弹窗实现。当用户长按或点击"查看角色详情"时，系统会显示包含使用统计信息的模态框。

具体实现方式：
1. 在角色选择页面的 `viewRoleDetail` 方法中，获取角色的详细信息
2. 从角色对象的 `usage` 属性中提取 `usageCount` 值
3. 将使用次数格式化后显示在详情内容中
4. 结合角色的其他信息（如描述、背景、性格等）一并展示

这种设计让用户能够直观地了解自己对各个角色的使用情况，增强了用户对角色的情感连接和使用粘性。

## 数据聚合查询示例

以下是几个典型的数据聚合查询示例，用于角色使用分析和推荐：

```javascript
// 查询用户的所有角色使用统计
db.collection('roleUsage')
  .where({ userId: 'user_123' })
  .orderBy('usageCount', 'desc')
  .get()

// 查询特定角色的所有用户使用情况
db.collection('roleUsage')
  .where({ roleId: 'role_001' })
  .orderBy('lastUsedTime', 'desc')
  .get()

// 获取用户的热门角色（使用次数最多的前5个）
db.collection('roleUsage')
  .where({ userId: 'user_123' })
  .orderBy('usageCount', 'desc')
  .limit(5)
  .get()

// 查询最近7天内使用过的角色
db.collection('roleUsage')
  .where({ 
    userId: 'user_123',
    lastUsedTime: db.command.gte(new Date(Date.now() - 7 * 24 * 60 * 60 * 1000))
  })
  .orderBy('lastUsedTime', 'desc')
  .get()
```

这些查询充分利用了 `roleUsage` 集合的索引设计，确保了查询性能和响应速度。
