## 登录组件

`login` 组件封装了用户登录流程，包含微信授权、用户信息获取和登录状态回调机制。组件通过 `wx.getUserProfile` 获取用户基本信息，并调用全局 `app.login` 方法完成登录逻辑。用户需勾选服务协议后方可进行登录操作。

组件在登录过程中处理了多种状态，包括加载中、错误提示和成功反馈。登录成功后，会触发 `success` 事件并传递用户信息，同时通过 `close` 事件通知父组件关闭登录弹窗。若用户未授权或登录失败，组件将显示相应错误提示。

**组件属性**：
- `show`: 控制组件是否显示
- 内部状态：`loading`（加载中）、`error`（错误信息）、`agreed`（是否同意协议）

**事件机制**：
- `success`: 登录成功时触发，携带用户信息
- `close`: 请求关闭组件时触发
- `error`: 登录失败时通过 Toast 提示用户

## 兴趣标签云组件

`interest-tag-cloud` 组件用于可视化展示用户的兴趣标签，支持动态字体大小、颜色方案和交互行为。组件根据用户兴趣数据生成标签云，适用于个人画像展示和兴趣分析场景。

### 数据加载与处理

组件通过 `userInterestsService.getInterestTagCloudData` 获取用户兴趣数据，支持按关键词或分类两种模式展示。数据加载支持自动刷新和手动刷新功能，可通过 `autoRefresh` 和 `showRefreshButton` 属性控制。

### 字体大小映射算法

字体大小根据兴趣值的相对强度动态计算：
1. 找出所有标签中的最小值（`minValue`）和最大值（`maxValue`）
2. 使用线性插值公式计算每个标签的字体大小：
   ```
   fontSize = minFontSize + (value - minValue) / (maxValue - minValue) * (maxFontSize - minFontSize)
   ```
3. 确保最小值标签使用 `minFontSize`，最大值标签使用 `maxFontSize`

### 颜色方案

组件提供亮色和暗夜两种配色方案：
- **亮色模式**：使用 `colorMap` 定义各类别的标准颜色
- **暗夜模式**：使用 `darkModeColorMap` 提供适配暗色背景的颜色
- 未分类标签使用基于标签名称生成的随机颜色，确保同一标签始终显示相同颜色

### 交互功能

- **点击交互**：点击标签时触发 `tagclick` 事件，携带标签数据，可用于跳转至兴趣详情页
- **刷新功能**：支持手动刷新按钮，触发 `refresh` 事件并重新加载数据
- **随机排序**：每次加载后对标签进行随机排序，避免布局固化

## 工具函数支持

### 情绪值处理（emotion.js）

`emotion.js` 提供完整的情感分析功能，包括：
- **情感类型定义**：喜悦、伤感、愤怒、焦虑、平静五种基本情绪
- **情感分析接口**：`analyzeEmotion` 调用云函数进行专业分析，`analyzeEmotionLocal` 提供本地关键词匹配的备选方案
- **结果处理**：生成情感报告和个性化建议，更新本地情感历史记录
- **辅助函数**：获取情绪中文标签、颜色映射和强度描述

该工具被多个组件用于情绪可视化，如情绪仪表盘、情绪历史等，实现了统一的情绪处理逻辑。

### 数据格式化（format.js）

`format.js` 提供通用的数据格式化方法：
- **时间处理**：支持时间戳格式化为日期时间字符串和相对时间（如"3分钟前"）
- **数值格式化**：添加千分位分隔符、格式化金额和百分比
- **隐私保护**：提供手机号、身份证号、银行卡号的脱敏格式化
- **文本处理**：限制文本长度并添加省略号
- **文件大小**：将字节数转换为可读的 KB、MB 等单位

这些格式化函数在用户界面中广泛使用，确保数据展示的一致性和用户体验。

## 组件使用最佳实践

### 属性配置建议

**登录组件**：
- 始终监听 `success` 和 `close` 事件以处理登录结果
- 在用户未登录时显示组件，登录成功后及时隐藏
- 可通过 `show` 属性与页面状态绑定实现条件渲染

**兴趣标签云组件**：
- 设置合理的 `maxTags` 值（建议10-30个）避免界面拥挤
- 根据主题调整 `minFontSize` 和 `maxFontSize`（建议12-24px）
- 使用 `useCategories` 属性选择展示维度（分类或关键词）
- 在暗夜模式下启用 `darkMode` 属性以获得最佳视觉效果

### 事件监听指南

**登录组件事件监听**：
```javascript
// 监听登录成功
this.selectComponent('#login').addEventListener('success', (e) => {
  const { userInfo, isNewUser } = e.detail;
  // 处理用户信息，跳转页面等
});

// 监听关闭请求
this.selectComponent('#login').addEventListener('close', () => {
  this.setData({ showLogin: false });
});
```

**兴趣标签云事件监听**：
```javascript
// 监听标签点击
this.selectComponent('#tagCloud').addEventListener('tagclick', (e) => {
  const { tag } = e.detail;
  wx.navigateTo({
    url: `/pages/interest-detail?name=${tag.name}`
  });
});

// 监听加载完成
this.selectComponent('#tagCloud').addEventListener('loaded', (e) => {
  console.log('标签云加载完成', e.detail.tags);
});
```

### 样式覆盖方法

组件支持通过外部样式类进行定制：
- 使用 `::after` 伪元素或 `externalClasses` 定义可覆盖的样式点
- 在页面样式中定义 `.custom-tag` 类并应用到组件
- 避免直接修改组件内部样式，保持封装性
- 对于标签云，可通过调整容器尺寸和 `text-align` 控制布局

通过合理配置属性、监听事件和适当样式覆盖，开发者可以灵活地将这些基础组件集成到各种业务场景中，同时保持一致的用户体验。
