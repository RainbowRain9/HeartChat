## 简介
兴趣标签云组件（`interest-tag-cloud`）用于可视化展示用户的兴趣偏好。该组件通过动态字体大小和颜色分布算法，直观呈现用户兴趣关键词或分类的权重差异。组件支持点击交互、自动加载与手动刷新，适用于用户画像、兴趣分析等场景。

## 核心功能
该组件主要实现以下功能：
- 根据用户兴趣数据生成标签云
- 支持按关键词或分类展示
- 动态字体大小反映兴趣权重
- 分类颜色映射增强可读性
- 支持点击查看详情
- 提供刷新机制与错误处理

## 属性说明
组件支持以下输入属性：

| 属性名 | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| userId | String | '' | 用户ID，必填 |
| maxTags | Number | 20 | 最大显示标签数量 |
| minFontSize | Number | 12 | 最小字体大小（px） |
| maxFontSize | Number | 24 | 最大字体大小（px） |
| colorMap | Object | 预设颜色映射 | 分类颜色映射对象（亮色模式） |
| darkModeColorMap | Object | 预设颜色映射 | 分类颜色映射对象（暗黑模式） |
| showCategory | Boolean | true | 是否显示分类信息 |
| autoRefresh | Boolean | false | 是否自动刷新数据 |
| darkMode | Boolean | false | 是否启用暗黑模式 |
| showTitle | Boolean | true | 是否显示标题 |
| showRefreshButton | Boolean | true | 是否显示刷新按钮 |
| useCategories | Boolean | true | 是否使用分类数据而非关键词数据 |

## 事件与方法
### 支持的事件
| 事件名 | 说明 | 事件详情 |
|-------|------|----------|
| tagclick | 标签点击事件 | `{tag: {name, value, category, color}}` |
| loaded | 标签加载完成事件 | `{tags: Array}` |
| error | 标签加载错误事件 | `{error: Error}` |
| refresh | 标签刷新事件 | 无 |

### 支持的方法
| 方法名 | 参数 | 说明 |
|-------|------|------|
| loadTags | forceRefresh: Boolean | 加载标签数据，forceRefresh为true时强制刷新 |
| handleRefresh | 无 | 处理刷新按钮点击事件 |

## 样式计算逻辑
组件内部根据权重值动态计算显示样式：

1. **字体大小计算**：
   - 获取标签权重最大值与最小值
   - 使用线性插值公式：`fontSize = minFontSize + (value - minValue) / (maxValue - minValue) * (maxFontSize - minFontSize)`
   - 确保字体大小在设定范围内

2. **颜色分配逻辑**：
   - 若标签有分类且非“未分类”，使用`colorMap`或`darkModeColorMap`中对应颜色
   - 否则基于标签名称生成一致的随机颜色（通过字符码求和作为种子）

3. **排序机制**：
   - 标签随机排序以避免每次显示顺序相同

## 交互行为
组件支持以下交互行为：

- **点击标签**：触发`tagclick`事件，可用于弹出详情模态框
- **刷新按钮**：点击后调用`loadTags(true)`重新获取数据
- **自动加载**：当`autoRefresh`为true时，组件挂载后自动加载数据
- **错误处理**：加载失败时显示错误信息并触发`error`事件

## 最佳实践
### 数据获取流程
1. 组件调用`userInterestsService.getInterestTagCloudData()`
2. 服务层优先读取缓存（有效期30分钟）
3. 缓存失效时调用云函数`user?action=getUserInterests`
4. 返回数据按权重或数量排序后传递给组件

### 性能优化建议
- 合理设置`maxTags`避免渲染过多节点
- 利用缓存机制减少云函数调用频率
- 在非关键页面设置`autoRefresh=false`手动控制加载时机

### 错误处理策略
- 空数据时显示友好提示
- 网络异常时保留上次有效数据或显示错误信息
- 提供刷新入口允许用户重试
