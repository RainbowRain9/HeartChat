## 云函数调用失败

云函数调用失败是常见的问题，可能由多种原因引起，包括网络连接问题、参数错误、权限问题等。

**症状**：
- 小程序前端调用云函数时，返回错误信息或无响应。
- 云函数日志中出现错误记录。

**处理方法**：
1. **检查网络连接**：确保设备网络连接正常。
2. **实现重试机制**：在前端代码中实现重试机制，以应对临时的网络波动。
3. **提供友好的错误提示**：在用户界面显示友好的错误提示，避免直接暴露技术细节。

```javascript
function callWithRetry(fn, retries = 3, delay = 1000) {
  return new Promise((resolve, reject) => {
    fn()
      .then(resolve)
      .catch(error => {
        if (retries === 0) {
          return reject(error);
        }
        
        setTimeout(() => {
          callWithRetry(fn, retries - 1, delay)
            .then(resolve)
            .catch(reject);
        }, delay);
      });
  });
}

// 使用重试机制调用云函数
callWithRetry(() => analyzeEmotion(messages))
  .then(result => {
    // 处理结果
  })
  .catch(error => {
    wx.showToast({
      title: '网络错误，请稍后再试',
      icon: 'none'
    });
  });
```

## AI接口超时

AI接口超时通常发生在调用外部API时，服务器响应时间过长或网络延迟较高。

**症状**：
- 调用AI模型API时，长时间无响应。
- 云函数日志中出现“连接超时”错误。

**处理方法**：
1. **设置合理的超时时间**：在调用API时设置合理的超时时间，避免无限等待。
2. **实现指数退避重试策略**：在重试时增加延迟时间，避免对服务器造成过大压力。
3. **检查API密钥和网络连接**：确保API密钥正确配置，网络连接稳定。

```javascript
// 为Claude模型设置更长的超时时间
let timeoutMs = 20000; // 默认20秒超时
if (platformKey === 'CLAUDE') {
  timeoutMs = 30000; // Claude模型设置30秒超时
}

const timeoutPromise = new Promise((_, reject) => {
  setTimeout(() => reject(new Error(`连接超时(${timeoutMs/1000}秒)`)), timeoutMs);
});

// 使用Promise.race来实现超时控制
const result = await Promise.race([
  aiModelService.generateChatReply(
    "测试连接",
    [],
    { prompt: "这是一个测试连接的请求，请简短回复。" },
    false,
    null,
    {
      platform: platformKey,
      max_tokens: 50 // 减少token数量，加快响应速度
    }
  ),
  timeoutPromise
]);
```

## 用户登录异常

用户登录异常可能由授权失败、云函数逻辑错误或数据库问题引起。

**症状**：
- 用户点击登录按钮后无反应或提示授权失败。
- 登录后无法获取用户信息。

**处理方法**：
1. **检查授权逻辑**：确保`wx.getUserProfile`和`wx.login`调用正确。
2. **验证云函数逻辑**：检查`login`云函数的`code2Session`获取openid逻辑。
3. **检查数据库配置**：确保`users`集合存在且字段定义正确。

```javascript
// login云函数实现code2Session获取openid
async function login(event, context) {
  const { code } = event;
  const app = cloud.init();
  const wxContext = cloud.getWXContext();

  try {
    const response = await app.openapi.sns.jscode2session({
      appid: wxContext.APPID,
      secret: wxContext.SECRET,
      js_code: code,
      grant_type: 'authorization_code'
    });

    const { openid, session_key } = response;

    // 查询或创建用户信息
    const db = cloud.database();
    const user = await db.collection('users').where({ openid }).get();

    if (user.data.length === 0) {
      await db.collection('users').add({
        data: {
          openid,
          create_time: new Date(),
          last_login_time: new Date(),
          status: 'active'
        }
      });
    } else {
      await db.collection('users').where({ openid }).update({
        data: {
          last_login_time: new Date()
        }
      });
    }

    return { openid, userInfo: user.data[0] };
  } catch (error) {
    console.error('登录失败:', error);
    return { success: false, error: error.message };
  }
}
```

## 情绪分析不准

情绪分析不准可能由AI模型提示词设计不当、数据预处理问题或模型本身限制引起。

**症状**：
- 情绪分析结果与用户输入内容不符。
- 关键词提取不准确或遗漏重要信息。

**处理方法**：
1. **优化提示词设计**：调整情感分析提示词，使其更明确地指导AI模型。
2. **检查数据预处理**：确保输入文本经过适当的清洗和格式化。
3. **验证模型配置**：检查AI模型的配置参数，如温度、最大输出token等。

```javascript
// 优化情绪分析提示词
const emotionPrompt = `
你是一个专业的情绪分析师。请分析以下对话内容，识别用户的主要情绪和次要情绪。
请直接返回JSON格式，包含以下字段：
- primary_emotion: 主要情绪（如：快乐、悲伤、愤怒、焦虑、平静等）
- secondary_emotion: 次要情绪（数组，包含1-3个情绪）
- keywords: 关键词（数组，提取3-5个最能代表情绪的关键词）
- analysis: 简短的分析说明（50字以内）

对话内容：
{{user_message}}
`;
```

## 日志分析方法

有效的日志分析是故障排除的关键。通过查看云函数日志，可以快速定位问题根源。

**步骤**：
1. **登录微信云开发控制台**：进入小程序的云开发控制台。
2. **选择云环境**：选择对应的云环境。
3. **导航到日志标签页**：在“云函数” -> “日志”中查看日志。
4. **筛选日志**：选择要查看的云函数和时间范围。

**优化日志输出**：
- **保留关键错误日志**：确保关键错误信息被记录。
- **减少不必要的日志**：在生产环境中减少详细日志输出，提高性能。

```javascript
// 关键错误日志保留，不需要条件判断
console.error('云函数调用失败:', error.message || error);
```

## 错误码解释

了解常见的错误码有助于快速诊断问题。

| 错误码 | 含义 | 处理方法 |
|-------|------|---------|
| 401 | 认证失败 | 检查API密钥配置 |
| 403 | 禁止访问 | 检查权限设置 |
| 429 | 请求过多 | 实现指数退避重试策略 |
| 500 | 服务器内部错误 | 检查云函数逻辑和日志 |

## 调试步骤

系统化的调试步骤可以帮助高效解决问题。

1. **复现问题**：在开发环境中尝试复现问题。
2. **查看日志**：检查云函数和前端日志，寻找错误信息。
3. **检查网络请求**：使用开发者工具检查网络请求和响应。
4. **验证配置**：确认所有配置文件和环境变量正确。
5. **逐步排查**：从问题的源头开始，逐步排查每个环节。

## 规避建议

为了减少问题的发生，提出以下规避建议。

2. **优化日志记录**：添加更详细的操作日志，便于问题排查。
3. **加强参数验证**：确保所有输入参数都经过严格检查。
4. **性能优化**：优化数据库查询，减少不必要的查询和更新操作。
