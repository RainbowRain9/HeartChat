## 常见问题分类

本指南针对 HeartChat 项目中常见的三类核心问题进行分类与诊断：  
- **云函数调用失败**：如错误码 50001，通常与网络、参数或权限相关。  
- **AI模型响应超时**：涉及外部 API 调用延迟或模型服务不可用。  
- **数据库查询为空**：数据未正确写入或查询条件不匹配。  

通过系统性排查，可快速定位并解决上述问题。

## 云函数调用失败（错误码50001）

错误码 50001 通常表示云函数调用失败，可能由以下原因导致：

### 诊断步骤
1. **检查日志输出**  
   - 在微信开发者工具中查看云函数日志，确认是否有异常堆栈或错误信息。  
   - 检查 `cloudfunctions/analysis/index.js` 的日志记录，确认函数是否正常进入执行流程。

2. **验证网络连接**  
   - 确保客户端网络正常，可通过 `miniprogram/utils/request.js` 检查基础请求是否可达。  
   - 使用微信开发者工具的“网络”面板监控请求状态码与响应时间。

3. **检查参数合法性**  
   - 确认调用云函数时传递的参数符合预期格式，如 `data` 字段是否为对象、必填字段是否存在。  
   - 检查 `miniprogram/services/cloudFuncCaller.js` 中的参数封装逻辑。

4. **权限与环境配置**  
   - 确认云开发环境 ID 配置正确，且云函数已部署至对应环境。  
   - 检查 `project.config.json` 中的 `cloudfunctionRoot` 和 `appid` 是否正确。

## AI模型响应超时

AI模型响应超时通常发生在调用智谱AI、Gemini等外部API时。

### 诊断步骤
1. **检查API密钥与配置**  
   - 确认 `bigmodel.js` 和 `geminiModel.js` 中的 API Key 已正确配置于环境变量或安全配置中。  
   - 检查 `cloudfunctions/analysis/aiModelService.js` 中的模型调用逻辑是否正确路由。

2. **验证网络可达性**  
   - 使用 `httpRequest` 云函数测试外部 API 地址是否可访问。  
   - 查看 `cloudfunctions/httpRequest/index.js` 日志，确认请求是否成功返回。

3. **调整超时设置**  
   - 在 `aiModelService.js` 中增加请求超时时间，避免因短暂延迟导致失败。  
   - 实现指数退避重试机制，提升容错能力。

4. **查看模型服务状态**  
   - 访问智谱AI、Gemini等平台的官方状态页，确认服务是否正常运行。

## 数据库查询为空

数据库查询返回空结果可能由数据未写入、索引缺失或查询条件错误引起。

### 诊断步骤
1. **确认数据已写入**  
   - 检查相关云函数（如 `analysis`）是否成功将数据写入 `emotion_records`、`messages` 等集合。  
   - 查看数据库控制台，手动查询集合是否存在预期记录。

2. **检查查询条件**  
   - 确认查询参数（如 `user_id`、`timestamp` 范围）是否正确传递。  
   - 检查 `userInterestAnalyzer.js` 中的聚合查询逻辑是否匹配实际数据结构。

3. **验证索引配置**  
   - 为常用查询字段（如 `user_id`、`chat_id`）创建数据库索引，提升查询效率。  
   - 参考 `user/createIndexes.js` 脚本确保索引已部署。

4. **日志追踪**  
   - 在 `index.js` 中添加日志，输出查询条件与返回结果数量，便于定位问题。

## test.js 测试文件使用方法

`test.js` 文件用于验证云函数逻辑，支持本地调试与模拟调用。

### 使用方法
1. **运行测试脚本**  
   - 进入 `cloudfunctions/analysis` 目录，执行 `node test.js` 启动测试。  
   - 可模拟调用 `keywordClassifier`、`userInterestAnalyzer` 等功能模块。

2. **修改测试输入**  
   - 在 `test.js` 中修改 `event.data` 模拟不同输入参数，验证函数输出是否符合预期。  
   - 示例：测试关键词分类功能时，传入不同文本观察分类结果。

3. **结合日志调试**  
   - 在测试过程中添加 `console.log` 输出中间变量，便于分析执行流程。  
   - 检查控制台输出是否包含预期的关键词、情感类型等信息。

4. **其他测试文件**  
   - `httpRequest/test.js`：测试外部 HTTP 请求逻辑。  
   - `roles/test-zhipu.js`：测试智谱AI接口调用。

## 调试技巧与性能优化建议

### 调试技巧
1. **使用 console.log 定位问题**  
   - 在关键函数入口、条件分支、返回前添加日志，输出参数与状态。  
   - 示例：在 `keywordClassifier.js` 中输出分类结果，验证逻辑正确性。

2. **利用微信开发者工具**  
   - 使用“网络”面板监控所有云函数调用，查看请求/响应详情。  
   - 使用“云开发”面板直接调用函数并查看实时日志。

3. **分段测试逻辑**  
   - 将复杂流程拆分为多个小函数，逐个测试确保每部分正常工作。

### 性能优化建议
1. **减少不必要的云函数调用**  
   - 合并可批量处理的请求，避免频繁调用。  
   - 使用本地缓存（如 `wx.setStorageSync`）存储频繁访问的数据。

2. **优化数据库查询**  
   - 为常用字段创建索引，避免全表扫描。  
   - 限制查询返回字段数量，减少数据传输开销。

3. **AI模型调用优化**  
   - 实现结果缓存机制，对相同输入避免重复调用。  
   - 使用流式响应（Stream）提升用户体验，避免长时间等待。

4. **前端性能优化**  
   - 利用 `miniprogram/services/chatCacheService.js` 实现聊天记录本地缓存。  
   - 延迟加载非关键组件，提升页面启动速度。
