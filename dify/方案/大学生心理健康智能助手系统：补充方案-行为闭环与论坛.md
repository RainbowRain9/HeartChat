# 基于多模态情感计算的大学生心理危机智能预警与干预系统——MindGuard｜补充方案（行为闭环与论坛）

本文为《大学生心理健康智能助手系统：终极整合MAX方案》的补充说明，聚焦于“从认知到行动”的闭环能力与论坛扩展模块，同时给出命名与隐私合规建议。

## 命名与定位
- 产品命名：MindGuard（基于多模态情感计算的大学生心理危机智能预警与干预系统）。
- 角色定位：从“助手”升级为“管家”（更强调主动关怀、持续陪伴与闭环执行）。
- 文案与UI：统一将“助手”替换为“管家”，涉及应用名称、导航、欢迎语、空状态提示与Push模板。

## 行为改变闭环模块（从认知到行动）
- 核心目标：让“建议”转化为“被记录且被完成的行动”，并以数据驱动持续优化。
- 典型流程（以“考试失利→从整理书桌开始”示例）：
  1) 评估与建议：评估到负性情绪/压力后，生成微行为建议（如“整理桌面10分钟”）。
  2) 任务创建：将建议落到“任务卡”（含截止时间、所需时间、步骤提示）。
  3) 轻提醒：到点温和提醒；若用户选择“稍后”，智能顺延且不骚扰。
  4) 执行回执：用户一键“开始/完成”，或用勾选/语音/照片打卡（多模态可选）。
  5) 回访复盘：T+1 或约定时间回访，复盘情绪与执行感受，形成正反馈。
  6) 数据沉淀：记录建议→接受→开始→完成的全链路事件，支持漏斗与依从性分析。

### 行为建议库（微习惯）
- 设计理念：参考《5%的改变》，提供低门槛、可复现、可量化、可组合的微习惯清单。
- 建议结构：`{场景标签, 目标情绪/认知, 步骤建议, 平均耗时, 预计收益, 备选方案}`。
- 适配策略：结合用户偏好、环境可用性和以往依从性，动态排序 Top3 建议。

### 智能体到建议映射（示例）
- 学业与考试压力 Agent：番茄钟10分钟、错题本回顾1页、整理复习清单3条。
- 社交关系 Agent（原“宿舍关系”）：共情练习1次、非暴力沟通开场句、主动问候室友1句。
- 恋爱情绪 Agent：分离注意5分钟、边界表达模板、共同计划1个微活动。
- 家庭关系 Agent：感谢信一句、电话3分钟、冲突情景脚本演练。

### 数据模型（建议）
- `behavior_tasks`：task_id, user_id, agent, title, steps, expected_minutes, due_at, status。
- `task_events`：event_id, task_id, type(issued/accepted/started/completed/skipped), ts, channel。
- `checkins`：checkin_id, user_id, mood_score, stress_score, note, ts, related_task_id?。
- `adherence_metrics`（可汇总视图）：按日/周统计接受率、启动率、完成率、平均执行时长、二次回访改善度。

### Dify 工作流草案（YAML伪）
```yaml
name: 行为闭环-任务创建与跟踪
trigger: 建议生成后
steps:
  - 写入 behavior_tasks
  - 安排提醒(到期-15min/到期时/宽限+30min)
  - 监听回执(按钮/文本/语音/图片)
  - 记录 task_events 与 checkins
  - 更新 adherence_metrics
  - 回访对话：复盘感受→更新个性化偏好
```

## 论坛模块（可选扩展）
目标：形成“数据→洞察→预警→干预→复盘”的公共空间闭环，同时保护隐私与安全。

### 能力清单
- 数据收集与本地训练：论坛帖子与评论经脱敏后入库，供本地向量检索与主题模型训练。
- 预警与追踪：
  - 基于发帖频率、情绪走向、主题切换与高危词共现，生成个人与群体风险信号。
  - 与私聊/对话线索合并，形成纵向时间线与风险轨迹图。
- 每日智能用户报表：主要情绪、风险信号、行为任务完成度、建议下一步（仅对本人或有授权的辅导岗位可见）。
- AI 与专家 PK：
  - 选定标准化问卷或真实但已脱敏案例，AI 与专家分别评分与分级，并输出理由链。
  - 用户对两者打分反馈至评测池，形成效果对比与改进闭环（含偏差监测与漂移预警）。

### 论坛数据管道（示例）
```yaml
name: 论坛-ingest-预警
trigger: 新帖/新评
steps:
  - 脱敏清洗 -> 写入 forum_posts
  - 向量化与主题标注 -> forum_embeddings/topics
  - 风险规则与模型打分 -> risk_signals
  - 合并用户纵向特征 -> user_timelines
  - 若超阈值 -> 异常告警(仅限授权角色)
```

### 数据表（建议）
- `forum_posts`：post_id, user_hash, text, media_refs, created_at, privacy_flag。
- `risk_signals`：signal_id, user_hash, source(论坛/私聊), risk_type, score, ts, evidence。
- `daily_reports`：user_id/hash, date, mood_summary, risk_summary, tasks_summary, next_best_actions。
- `evaluation_rounds`（PK评测）：case_id, ai_score, expert_score, user_vote, rubric_version, ts。

## 特情场景与人工转交（隐私优先）
- 升级策略：分层阈值与分级处置，支持“用户同意后再转交”的显性授权。
- 转交对象：
  - 校内：辅导员/心理中心坐席（建议采用匿名或化名+最小必要信息）。
  - 校外：24小时匿名热线与公益机构（默认匿名）。
- 隐私与合规模块：
  - 最小化可识别信息：默认仅共享情绪等级、风险类型、时间窗、建议行动摘要。
  - 同意收集与审计：记录授权来源、范围与有效期；所有查看均留审计日志。
  - 角色与范围控制：基于RBAC/ABAC限制可见字段与操作动作。
  - 紧急例外：当存在明确自伤/他伤高危且用户失联时，触发应急流程并同步审计记录。

## 多模态情感计算（演进路线）
- 可选模态：语音通话情感（音高/语速/停顿）、图像面部表情（本地推理）、键鼠行为节律等。
- 原则：隐私优先、边缘计算优先、用户显式开关；默认文本为主，逐步A/B开启其他模态。

## 度量与看板（关键指标）
- 行为依从性：建议接受率、任务启动率、完成率、复访改善度。
- 风险控制：高危信号响应时延、升级准确率、误报/漏报率。
- 体验满意度：对话评分、PK投票偏好、NPS/CSAT。

## 落地节奏（建议）
1) 先把行为闭环做细做稳：任务卡+提醒+回访+依从性看板。
2) 再上线论坛ingest与安全基线（脱敏、RBAC、审计）。
3) 最后做PK评测闭环与多模态A/B，逐步提升模型可信度与有效性。
