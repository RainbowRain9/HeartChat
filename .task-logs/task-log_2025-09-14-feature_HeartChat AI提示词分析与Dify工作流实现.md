### 3. Dify工作流设计与实现

#### 工作流架构
设计了完整的10节点处理流程：
1. **开始节点** - 接收用户输入和上下文
2. **文本预处理** - 清理文本、提取关键词、统计特征
3. **模型选择路由** - 根据文本复杂度智能选择AI模型
4. **情感分析** - 使用选定模型进行深度情感分析
5. **结果验证** - 验证JSON格式和数据完整性
6. **风险评估** - 根据风险等级自动分类和处理
7. **增强建议生成** - 提供认知、行为、表达三个层面建议
8. **数据整合** - 整合所有分析结果
9. **数据存储** - 将结果存储到云数据库
10. **结束节点** - 输出最终结果

#### 智能模型选择策略
```
文本复杂度 < 0.3 → GPT-3.5-turbo (成本优化)
文本复杂度 0.3-0.7 → GLM-4 (中文优化)
文本复杂度 > 0.7 → GPT-4 (深度分析)
```

#### 风险分级管理
- **低风险(0-2)**: 正常监控、保持关注、提供一般建议
- **中风险(3-4)**: 适当关注、提供支持资源、建议自我调节
- **高风险(5)**: 立即关注、建议专业帮助、持续监控

3. **modelUsageStats** - 模型使用统计表（记录使用情况）

- 智能模型选择和A/B测试

```javascript
function preprocessText(text) {
  // 去除特殊字符，保留中文、英文、数字和基本标点
  let cleanedText = text.replace(/[^\u4e00-\u9fa5\w\s\.,!?，。！？、；：""''（）【】]/g, '');

  // 提取关键词和统计特征
  const keywords = extractKeywords(cleanedText);
  const textStats = {
    length: cleanedText.length,
    sentence_count: cleanedText.split(/[。！？.!?]/).filter(s => s.trim()).length,
    emotion_words: detectEmotionWords(cleanedText),
    complexity: calculateComplexity(cleanedText)
  };

  return { cleaned_text: cleanedText, keywords: keywords, text_stats: textStats };
}
```
