# HeartChat 情感分析提示词优化实现说明

## 概述

本文档说明了如何将优化后的情感分析提示词集成到HeartChat项目中。新的提示词体系针对不同AI模型进行了专门优化，提供了更精准的情感分析和情商提升建议。

## 主要改进点

### 1. 情感类型系统
- 建立了8大类32子类的完整情感分类体系
- 提供了详细的情感描述和示例
- 便于AI模型进行更精准的情感识别

### 2. 强度评分标准
- 定义了0.0-1.0的五级强度评分标准
- 提供了具体的判断依据
- 包含词汇强度、重复频率、标点符号等多个维度

### 3. 新增字段支持
新增了以下字段以提供更丰富的情感分析：
- `emotion_pattern`: 情感模式类型（爆发型、累积型、波动型等8种）
- `change_rate`: 情感变化速度（0.0-1.0）
- `triggers_analysis`: 触发因素深度分析
- `eq_suggestions`: 情商提升具体建议（3条）
- `risk_level`: 情感风险预警等级（0-5）
- `context_influence`: 上下文影响程度（0.0-1.0）

需要修改`cloudfunctions/analysis/aiModelService.js`文件中的`analyzeEmotion`函数，根据不同的模型类型使用对应的优化提示词。

```javascript
/**
 * 获取优化后的提示词
 * @param {string} text 待分析文本
 * @param {Array} history 历史消息
 * @param {string} platform 平台类型
 * @returns {string} 优化后的提示词
 */
function getOptimizedPrompt(text, history, platform) {
  // 基础提示词模板
  const basePrompt = `你是一个专业的情感分析AI助手...`;
  
  // 根据不同平台返回不同的提示词
  switch(platform.toUpperCase()) {
    case 'GEMINI':
      return getGeminiPrompt(text, history);
    case 'OPENAI':
    case 'CROND':
      return getOpenAIPrompt(text, history);
    case 'ZHIPU':
      return getZhipuPrompt(text, history);
    case 'CLOSEAI':
      return getDeepSeekPrompt(text, history);
    default:
      return basePrompt;
  }
}
```

### 4. 前端兼容性处理

由于新增了字段，需要确保前端组件能够正确处理：

```javascript
// miniprogram/utils/emotion.js

/**
 * 情感分析结果处理工具
 */
const emotionUtils = {
  /**
   * 兼容处理新旧字段
   * @param {Object} result 分析结果
   * @returns {Object} 处理后的结果
   */
  normalizeResult(result) {
    return {
      // 基础字段（兼容旧版）
      type: result.primary_emotion || result.emotion_type || '平静',
      intensity: result.intensity || 0.5,
      keywords: result.topic_keywords || result.keywords || [],
      
      // 新增字段（提供默认值）
      emotion_pattern: result.emotion_pattern || '稳定型',
      change_rate: result.change_rate || 0.0,
      triggers_analysis: result.triggers_analysis || '',
      eq_suggestions: result.eq_suggestions || [],
      risk_level: result.risk_level || 0,
      context_influence: result.context_influence || 0.5,
      
      // 保留其他字段
      ...result
    };
  },
  
  /**
   * 获取风险等级描述
   * @param {number} level 风险等级
   * @returns {string} 描述文本
   */
  getRiskLevelDescription(level) {
    if (level <= 2) return '低风险';
    if (level <= 4) return '中风险';
    return '高风险';
  }
};

module.exports = emotionUtils;
```

### 5. 组件更新示例

情感分析面板组件需要更新以支持新字段：

```javascript
// miniprogram/components/emotion-panel/emotion-panel.js

Component({
  properties: {
    analysisData: {
      type: Object,
      value: {},
      observer: function(newVal) {
        if (newVal) {
          this.setData({
            normalizedData: emotionUtils.normalizeResult(newVal)
          });
        }
      }
    }
  },
  
  data: {
    normalizedData: null
  },
  
  methods: {
    // 显示情商建议
    showEqSuggestions() {
      const suggestions = this.data.normalizedData.eq_suggestions || [];
      if (suggestions.length > 0) {
        wx.showModal({
          title: '情商提升建议',
          content: suggestions.join('\n\n'),
          showCancel: false
        });
      }
    },
    
    // 显示风险提示
    showRiskWarning() {
      const riskLevel = this.data.normalizedData.risk_level || 0;
      if (riskLevel >= 3) {
        wx.showModal({
          title: '情感风险提醒',
          content: '检测到您的情感状态需要关注，建议寻求专业帮助。',
          confirmText: '我知道了',
          showCancel: false
        });
      }
    }
  }
});
```

## 注意事项

1. **向后兼容**：新字段都是可选的，不会影响现有功能
2. **性能考虑**：提示词变长可能增加API调用时间和成本
3. **模型差异**：不同模型对新特性的支持程度可能不同
4. **用户引导**：考虑添加引导帮助用户理解新的分析维度
